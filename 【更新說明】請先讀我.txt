交通服務水準分析 — GitHub Pages 更新包 v2.20.3
=================================================

本版沒有變更任何計算規則、判定門檻或操作流程。
-----------------------------------------------------------------

■ v2.20.3：結論草稿的「條件範本」會跟著專案包走了

  範本只存在當下那一台電腦的瀏覽器裡，而「下載專案包」與
  「個人全部計畫包」都沒有把它收進去——在 A 電腦存了好幾組常用條件，
  帶到 B 電腦匯入之後一組都不會出現，畫面卻只說匯入成功。
  本版把 conclusionTemplates 一併收進兩種包，匯入時還原回去。

  只有備份檔實際帶著這個欄位時才覆蓋該計畫的範本；
  匯入舊版專案包不會把本機既有的範本清掉。
  升版前下載的舊包裡本來就沒有範本，請使用者重新下載一份。

  新增 backup-completeness.test.mjs（4 項）。

■ v2.20.2：Excel 解析多了一道邊界檢查

  本系統的 SheetJS 已經是官方 0.20.3（安全警示的修正版），
  這一版再加一層：解析時關掉用不到的公式、內嵌 HTML 與巨集；
  解析前後比對瀏覽器的內建物件，一旦某個檔案真的動到它，
  就當場中止這次匯入並指出是哪一個檔案，而不是安靜地繼續。
  即使日後元件版本被換回舊版，也不會無聲通過。

■ v2.20.2：備份包在 Windows 上更容易自行驗證

  測試用的瀏覽器尋找順序補上 Windows 的 Chrome 與 Edge、
  以及 macOS 與 Linux 的常見安裝位置——多數人是在自己的 Windows 電腦
  打開這個備份包，本機已經有瀏覽器時就不必再另外下載一份。


如何更新
-----------------------------------------------------------------
把本壓縮檔內的所有檔案，覆蓋到 GitHub repository
（https://github.com/baotoast/Travel-speed）的根目錄，然後 commit + push。
GitHub Pages 會自動重新發布，約 1～3 分鐘。

**請先手動刪除舊版檔案**（檔名帶版號，上傳不會自動刪掉舊的）：
  manuals 資料夾裡所有不是 v2.20.3 的
  交通服務水準分析系統_新手使用手冊_*.pdf 與 .docx；
  以及根目錄的 VALIDATION_v2.20.2.md（本版改名為 VALIDATION_v2.20.3.md）。

部署完成後請確認：左上角顯示「正式版 v2.20.3」，
「新手說明」頁的兩個下載連結點得下去（不是 404）。
